## 📜 Desafio DIO: Wireframe de Média Fidelidade (One Page) - Guru Certificate ☁️

Este é o repositório do projeto desenvolvido como parte do desafio da **Digital Innovation One (DIO)** focado na criação de um **Wireframe de Média Fidelidade (One Page)**, aplicando conceitos de **Psicologia Aplicada ao Design** e **Leis de Usabilidade**.

O produto escolhido para este desafio é o **Guru Certificate**, uma plataforma fictícia de **simulados online** para ajudar profissionais a obterem **certificações da Amazon Web Services (AWS)**.

---

### 💡 Produto: Guru Certificate

O **Guru Certificate** visa ser o recurso definitivo para a preparação de exames de certificação AWS. A página *One Page* (página única) foca em apresentar os principais simulados disponíveis (por exemplo, AWS Certified Solutions Architect - Associate, AWS Certified Developer - Associate, etc.), destacar os benefícios do serviço e guiar o usuário de forma intuitiva à ação principal.

---

### 🎯 Objetivos de Aprendizagem (do Desafio)

Ao realizar este desafio, pude focar na aplicação prática dos seguintes conceitos:

* **Criação/Melhoria de Wireframe:** Desenvolver um **wireframe de média fidelidade** para o conceito do produto Guru Certificate.
* **Aplicação de Usabilidade e Psicologia:** Incorporar ativamente as **Leis de Usabilidade** (como as de **Bastien** e **Nielsen**) e a **Psicologia do Design** para garantir uma interface **intuitiva**, **funcional** e **persuasiva**.
    * *Exemplos de aplicação:* Uso de hierarquia visual para guiar o olhar (Psicologia Gestalt), minimização da carga cognitiva, consistência na navegação (Heurísticas de Nielsen), e clareza nos *Call-to-Actions* (CTAs).
* **Utilização de Ferramenta de Design:** Utilizar o **Figma** (ou ferramenta similar) para a prototipagem e desenvolvimento eficiente do wireframe.
* **Documentação e Exposição:** Documentar as decisões de design e apresentar o trabalho de forma organizada neste repositório do **GitHub**.

---

### 📝 Descrição do Wireframe

O wireframe do **Guru Certificate** foi desenvolvido como uma *One Page* com as seguintes seções principais, seguindo um fluxo lógico e priorizando a conversão:

1.  **Header/Hero Section:**
    * **Título e Proposta de Valor (H1):** Forte e claro, comunicando o benefício principal ("Passe na sua certificação AWS com nossos simulados").
    * **Imagem/Ilustração:** Elemento visual relevante para certificações/cloud.
    * **CTA Principal:** Proeminente, guiando para o início da jornada.
2.  **Certificações Disponíveis:**
    * **Cartões (Cards):** Blocos distintos para cada certificação (ex: Solutions Architect, Developer), com ícones e um breve resumo.
    * **Princípio de Agrupamento:** Uso eficaz para separar visualmente as opções (Psicologia da Gestalt).
3.  **Por que Guru Certificate? (Vantagens/Diferenciais):**
    * Seção dedicada a construir **confiança** e destacar **benefícios** (ex: questões atualizadas, modo de prova real, *feedback* detalhado).
4.  **Testemunhos/Provas Sociais:**
    * Aplicação do princípio de **Prova Social** (Psicologia Aplicada) para aumentar a credibilidade.
5.  **CTA Final/Footer:**
    * Repetição do CTA de forma clara e visível.
    * Links de navegação essenciais e informações de contato.
